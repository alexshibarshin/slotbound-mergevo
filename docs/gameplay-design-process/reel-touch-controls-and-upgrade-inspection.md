# Сенсорное управление барабанами и просмотр уровней

## Цель

- **Сделать управление барабанами удобнее, а состояние прокачки — читаемее**
  - Позволить выполнять Nudge непосредственно жестом по нужному барабану.
  - Перед выбором перка дать игроку доступ к уровням всех героев на каждом барабане.

## Сущности

- **Игровая слот-машина**
  - Три барабана, одновременно образующие поле 3×3.
- **Информационная слот-машина на экране Reel Upgrade**
  - Сохраняет визуальное окно 3×3, но каждый из трёх барабанов содержит по одному символу каждого из пяти героев.
- **Символ героя**
  - На экране Reel Upgrade показывает уровень/число звёзд данного героя именно на данном барабане.

## Действия

- **Nudge вниз свайпом**
  - *Как меняет стейт:* сдвигает выбранный барабан на один символ в том же направлении, что и текущая кнопка Nudge.
  - *Как выполняется:* свайп пальцем вниз непосредственно по выбранному барабану.
  - *Факторы эффективности:*
    - Текущие символы на барабане.
    - Доступность Nudge по действующим правилам.
- **Nudge вверх свайпом**
  - *Как меняет стейт:* сдвигает выбранный барабан на один символ в обратном направлении.
  - *Как выполняется:* свайп пальцем вверх непосредственно по выбранному барабану.
  - *Факторы эффективности:*
    - Boolean-флаг конфигурации, разрешающий обратный Nudge.
    - Текущие символы на барабане.
    - Доступность Nudge по действующим правилам.
- **Просмотр уровней героев на барабане**
  - *Как меняет стейт:* прокручивает только визуальное содержимое выбранного информационного барабана; не меняет игровой результат, уровни или ресурсы.
  - *Как выполняется:* плавное вертикальное перетаскивание выбранного барабана вверх или вниз с циклическим появлением соседних символов.
  - *Факторы эффективности:*
    - Читаемость уровня/числа звёзд на каждом символе.
    - Возможность быстро увидеть всех пяти героев через окно высотой в три символа.

## Механики

- **Свайповый Nudge**
  - Жест распознаётся отдельно для каждого барабана.
  - Свайп вниз дублирует существующий Nudge-контроль.
  - Свайп вверх выполняет обратный Nudge только при включённом boolean-флаге.
  - Один свайп сдвигает игровой барабан ровно на один символ и расходует Nudge по тем же правилам, что кнопка.
  - Кнопки Nudge остаются альтернативным способом управления.
- **Информационные барабаны Reel Upgrade**
  - Последний выпавший результат не используется как содержимое витрины.
  - Каждый барабан имеет фиксированный набор из пяти разных героев, по одному символу на героя.
  - Одновременно видны три символа на барабан — общий визуальный формат остаётся 3×3.
  - Барабан можно плавно и циклически прокручивать пальцем в обоих направлениях.
  - После отпускания барабан доворачивается до ближайшей строки; достаточно длинное движение может пройти две строки.

## Решения

- **Какой перк выбрать**
  - *Входная информация:* уровни всех пяти героев на каждом из трёх барабанов и эффекты предложенных перков.
  - *Действия на выбор:* выбрать один из трёх перков.
  - *Почему это интересно:* игрок может сопоставить перк с реальным распределением прокачки по барабанам.
  - *Когнитивная нагрузка:* 4/10; дополнительная информация скрыта за знакомым прямым манипулированием барабаном.
  - *Как эволюционирует в сессии:* по мере различия уровней героев между барабанами ценность точного просмотра растёт.

## Циклы

- Крутка -> оценка результата -> Nudge жестом или кнопкой -> разрешение результата.
- Открытие Reel Upgrade -> прокрутка информационных барабанов -> сравнение уровней и эффектов -> выбор перка.

## Метафора и арт-стиль

- Поведение вертикального барабана напоминает колесо выбора времени в iOS: прямое перетаскивание, плавное движение, появление следующего элемента с противоположного края.
- Внешний вид слот-машины и окно 3×3 не меняются.

## Рабочая зона

### Принятые детали управления

- Игровой Nudge дискретный: один завершённый свайп — один сдвиг на символ.
- Обратный Nudge использует тот же запас Nudge, что и прямой.
- Информационные барабаны стартуют с первых трёх героев из общего порядка героев и прокручиваются независимо.
